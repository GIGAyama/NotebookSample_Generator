# ノート見本作成ツール PRO

小学校のノート指導で使う **ノート見本（板書計画）** を、画面で作ってそのまま A4 に印刷できるツールです。

「マスの数を数えながら黒板に書き写す」「見本を毎回手書きする」といった準備を、
入力欄に文章を打つだけで終わらせることを目指しています。

**▶ 公開ページ: https://notebooksample-generator.giga-school.com/**

インストールは不要です。ブラウザで開けばすぐ使えます。

> **先生向けの使い方説明は [docs/manual/manual.md](docs/manual/manual.md) にあります**
> （公開ページ: https://giga-school.com/apps/notebooksample-generator/manual/ ）。
> 専門用語を使わず、「うまくいかないとき」の対処もまとめています。

## ✏️ できること

### 用紙をつくる

- **テンプレートを選ぶだけ** — 下の5種類から選ぶと、マス数・行数・縦横・用紙の向きがまとめて切り替わります

  | テンプレート | マス数 × 行数 | 書字方向 | 用紙の向き |
  |---|---|---|---|
  | 国語 15マス | 15 × 10 | 縦書き | A4 縦 |
  | 国語 12マス | 12 × 8 | 縦書き | A4 縦 |
  | 算数 17マス | 17 × 12 | 横書き | A4 横 |
  | 算数 22マス | 22 × 15 | 横書き | A4 横 |
  | 原稿用紙 400字 | 20 × 20 | 縦書き | A4 横（固定） |

- **カスタム設定** — 1行のマス数（5〜30）・行数（3〜25）・縦書き／横書き・文字の大きさ（30〜100%）を自由に調整
  （テンプレートを選んだあとに値を変えると、自動的に「カスタム設定」に切り替わります）
- **マス目の種類**を3種類から選択 — 「十字リーダーあり（緑）」「マス目のみ（緑）」「枠線なし（白紙）」
- **ヘッダー欄**（月・日・題名・なまえ）の表示を ON / OFF
- 用紙の向き（A4 縦／横）は、マスの並びから**自動で決まります**
- 文章が1ページに収まらないときは**自動で次のページに続きます**（枚数の上限なし）
- 句読点・閉じかっこが行頭に来ないように**禁則処理**します

### 文章を見本らしくする

- **【め】【も】【問】【じ】【自】【ま】** を打つと、めあて・問い・まとめなどの丸囲み記号になります
- 赤線・青線・黒線、赤字、囲み枠、片側の太線、穴埋め枠を文章中の記号で指定できます
- **プレビューをドラッグして装飾** — 右側の見本の上で文字をなぞって選ぶと、
  その場にツールバーが出て「線（黒・赤・青）／赤字／図形 △□○／穴埋め／枠線（囲み・左・右・上・下）／クリア」を
  ボタンで適用できます。記号は左の入力欄に自動で書き込まれるので、記号を覚えなくても使えます
- **【△1】【□2】【○3】** のように書くと、図形の中に文字を入れられます
- `4/1` のような日付は、斜線入りの**日付マス**になります
- `12` のような2桁以上の半角数字は、**1マスにまとめて**表示します（算数用）

### 子どもに合わせる

- **支援モード** — 「なぞり書き用（薄文字）」「穴埋め用（漢字・カタカナを空欄に）」に切り替え
- **学習時間の予測** — 学年ごとの書字速度（1年 10字/分・2年 15・3年 20・4年 25・5年 30・6年 35字/分）から、
  書き写しにかかる目安時間と文字数を画面上部に表示
- **書き分けの警告** — 行をまたいで漢字の熟語やカタカナ語が分断されそうな箇所を検知し、
  画面上部に「警告: N件」として一覧表示します

### 出力・保存

- **A4 印刷 / PDF 保存**（`Ctrl + P`）— 全ページが印刷されます
- **PNG 画像として保存**（`Ctrl + E`）— **1ページ目のみ**が画像になります（`notebook-sample_〈時刻〉.png`）
- 作ったノートに名前を付けて保存し、あとから呼び出し（保存先は端末のブラウザ内）
- バックアップの書き出し／読み込み（`notebook_data_backup.json`）。
  読み込みは**追加（マージ）**で、同じノートは重複しません
- **PWA 対応** — ホーム画面に追加すればアプリのように起動し、**オフラインでも動きます**
- **Google ドライブ同期（任意）** — 職員室のPCと教室のタブレットで同じノートを共有
- スマートフォン・タブレットでは、設定欄が左からのドロワーとして開きます

### 文章中で使える記号

| 記号 | 表示されるもの |
|---|---|
| `【め】` `【も】` `【問】` | 青い丸囲み文字（以降の行が青枠で囲まれます） |
| `【ま】` | 赤い丸囲み文字（以降の行が赤枠で囲まれます） |
| `【じ】` `【自】` | 丸囲み文字（枠は解除されます） |
| `【終】` | 枠の終わり（空行でも解除されます） |
| `【赤線】` `【青線】` `【黒線】` … `【線終】` | はさんだ部分に傍線 |
| `【赤字】` … `【字終】` | はさんだ部分を赤字に |
| `【穴】` … `【穴終】` | はさんだ部分を穴埋め枠に（点線の空欄になります） |
| `【枠】` … `【枠終】` | はさんだ部分を太い黒枠で囲む |
| `【左】` `【右】` `【上】` `【下】` … `【左終】` 等 | 片側だけに太い黒線（ノートを区切る補助線） |
| `【○テスト】` `【□2】` `【△3】` | 図形の中に文字（1マスに収まります） |
| `4/1` のような日付 | 斜線入りの日付マスとして表示 |
| `12` `345` のような2桁以上の半角数字 | 1マスにまとめて表示 |

記号そのものは印刷されません。`【` `】` は**全角**で入力してください（半角 `[ ]` は認識されません）。

主なショートカットはアプリ内の **F1**（または `Ctrl + /`）で一覧表示できます。

## 🔐 セキュリティ設計（扱うデータ／扱わないデータ）

このツールは **サーバーを持ちません。** 配信元（GitHub Pages）は完成した HTML と JavaScript を
配るだけで、入力内容を受け取ることも記録することもありません。

### 扱わないデータ

- **児童の氏名・学籍番号・成績などの個人情報は一切扱いません。** 入力欄そのものがありません
- 利用者の行動ログ、アクセス解析、広告トラッカーの類は入れていません
- パスワードやトークンをアプリ側で保管することはありません
  （アクセストークンはメモリ上のみで保持し、保存しません）

### 扱うデータと、その保存先

| データ | どこに保存されるか | 誰が見られるか |
|---|---|---|
| 編集中の設定（`notebookToolState_v3`） | 使っている端末のブラウザ内（localStorage） | その端末を使う人だけ |
| 保存したノート一覧（`notebookToolSavedNotes`） | 同上 | 同上 |
| 同期の接続状態・自動同期の ON/OFF（`notebookGDriveConnected` / `notebookGDriveAutoSync`） | 同上 | 同上 |
| ノートのバックアップ（同期を使う場合のみ） | **ログインした先生ご本人の Google ドライブ** | そのアカウントの持ち主だけ |

### Google ドライブ同期について

- 使うかどうかは **任意** です。使わなくてもすべての機能が動きます
- 要求する権限は **`drive.file`（このアプリが作ったファイルだけ）** と、ログイン中のアカウントを
  画面に表示するための `openid` / `email` のみです。
  **先生の他のドライブのファイルには技術的にアクセスできません**
- 同期の対象は「保存したノート一覧」だけです（編集中の作業内容は同期しません）
- 保存されるファイルは `notebook_sample_backup.json` の 1 つだけです
- 連携解除ボタンでアクセストークンを失効させ、端末側の接続情報も消去します
  （ドライブ上のバックアップファイル自体は残ります。不要なら Google ドライブ側で削除してください）
- 設定手順は [`docs/google-drive-sync.md`](docs/google-drive-sync.md) を参照してください

### 外部への通信先（これがすべてです）

| 宛先 | 用途 | いつ |
|---|---|---|
| `fonts.googleapis.com` / `fonts.gstatic.com` | 本文フォント（Zen Maru Gothic）の取得 | 初回表示時。以降はキャッシュ |
| `accounts.google.com` | Google ログイン画面・認証スクリプト | 同期を使うときだけ |
| `www.googleapis.com` | ドライブへの読み書き・アカウント表示 | 同期を使うときだけ |

`index.html` の Content-Security-Policy で、この4つ以外への通信を禁止しています。

## ⚠️ 制限とクォータ

- **データは端末のブラウザに保存されます。** ブラウザの「閲覧履歴・サイトデータの削除」を実行すると
  保存したノートも消えます。大切なものは「データ管理」からエクスポートするか、
  Google ドライブ同期を有効にしてください
- **共用端末では注意してください。** 同じブラウザプロファイルを使う人は保存内容を見られます
- **削除は自動同期されません。** 取りこぼしを防ぐ統合方式のため、片方の端末で消しても、
  もう片方に残っていれば復活します。完全に消す場合は各端末で削除してください
- localStorage の容量上限は概ね 5MB 程度です。ノートを大量に保存すると保存に失敗することがあります
  （失敗しても既存データは壊れません）
- **印刷は A4 縦／横を前提**にしています。ブラウザの印刷設定で「背景のグラフィック」を
  有効にしてください（罫線や色が出ないときの原因はほぼこれです）
- **PNG 書き出しは1ページ目だけ**です。2ページ目以降も画像で欲しい場合は、印刷・PDF をお使いください
- 原稿用紙 400字を選んでいる間は、マス数・行数・縦横・マス目の種類・ヘッダーは変更できません
  （文字の大きさだけ変更できます）
- 「警告」は漢字どうし・カタカナどうしの行またぎだけを見る簡易チェックです。
  日本語として正しい改行かどうかまでは判定しません
- Google ドライブ API には利用者ごとの回数制限があります。通常の使い方で当たることはまず
  ありませんが、同期を短時間に繰り返すと一時的に失敗することがあります
- 教科書体（UD Digi Kyokasho）は **端末にインストールされている場合のみ**使われます。
  無い端末では代替フォントで表示されます

## 🛠 開発

```bash
npm ci          # 依存をインストール
npm run dev     # 開発サーバー（http://localhost:5173）
npm test        # テスト（node:test）
npm run check   # 品質ゲート（必須ファイル・秘密情報・巨大ファイルの検査）
npm run quality # check と test をまとめて実行
npm run build   # 本番ビルド（dist/ に出力）
npm run preview # ビルド結果をローカルで確認
```

Google ドライブ同期をローカルで試す場合は、`.env.example` を `.env` にコピーして
`VITE_GOOGLE_CLIENT_ID` を設定してください（未設定でもビルドは通り、同期機能だけが
「初期設定が必要です」と表示されます）。

### 構成

| ファイル | 役割 |
|---|---|
| `index.html` | エントリ HTML。CSP・PWA 用のメタタグを持つ |
| `src/main.jsx` | React のマウント |
| `src/App.jsx` | 画面の組み立て・用紙のレンダリング・ショートカット・装飾ツールバー |
| `src/parseText.js` | 見本テキストの解析（文章 → マス目 → ページ）。React 非依存の純関数 |
| `src/googleDrive.js` | Google ドライブ連携（OAuth・読み書き・統合） |
| `src/useGoogleDriveSync.js` | 同期の状態管理フック |
| `vite.config.js` | ビルド設定・PWA マニフェスト |
| `tests/` | 中核ロジックのテスト（`node:test`。依存を増やさない方針） |
| `scripts/` | 品質ゲート。GIGA 共通の正本（SchoolPlan_Editor）と同一内容 |
| `quality.config.json` | 品質ゲートの設定（必須ファイル・除外ディレクトリ等） |
| `docs/google-drive-sync.md` | Google ドライブ同期のセットアップ手順 |
| `.github/workflows/deploy.yml` | CI と GitHub Pages への公開 |

`main` ブランチへの push で GitHub Actions が
`npm audit` → `npm run check` → `npm test` → `npm run build` を実行し、
すべて通ったときだけ GitHub Pages へ公開します。
