# ノート見本作成ツール PRO

小学校のノート指導で使う **ノート見本（板書計画）** を、画面で作ってそのまま A4 に印刷できるツールです。

「マスの数を数えながら黒板に書き写す」「見本を毎回手書きする」といった準備を、
入力欄に文章を打つだけで終わらせることを目指しています。

**▶ 公開ページ: https://gigayama.github.io/NotebookSample_Generator/**

インストールは不要です。ブラウザで開けばすぐ使えます。

> **先生向けの使い方説明は [MANUAL.md](MANUAL.md) にあります。**
> 専門用語を使わず、「うまくいかないとき」の対処もまとめています。

---

## ✏️ できること

- **テンプレートを選ぶだけ** — 国語 15マス／12マス（縦書き）、算数 17マス／22マス（横書き）、原稿用紙 400字
- マスの数・行数・文字サイズ・縦書き／横書きを自由に調整（カスタム設定）
- **【め】【も】【問】【じ】【自】【ま】** を打つと、めあて・問い・まとめなどの丸囲み記号になります
- 赤線・青線・黒線、赤字、囲み枠、穴埋め枠を文章中の記号で指定できます
- **支援モード** — 「なぞり書き用（薄文字）」「穴埋め用（漢字・カナを空欄に）」に切り替え
- **学習時間の予測** — 学年ごとの書字速度（1年 10字/分 〜 6年 35字/分）から目安時間を表示
- **A4 印刷 / PDF 保存 / PNG 画像として保存**
- 作ったノートに名前を付けて保存し、あとから呼び出し
- **PWA 対応** — ホーム画面に追加すればアプリのように起動し、**オフラインでも動きます**
- **Google ドライブ同期（任意）** — 職員室のPCと教室のタブレットで同じノートを共有

### 文章中で使える記号

| 記号 | 表示されるもの |
|---|---|
| `【め】` `【も】` `【問】` | 青い丸囲み文字（以降の行が青枠で囲まれます） |
| `【ま】` | 赤い丸囲み文字（以降の行が赤枠で囲まれます） |
| `【じ】` `【自】` | 丸囲み文字（枠は解除されます） |
| `【終】` | 枠の終わり |
| `【赤線】` `【青線】` `【黒線】` … `【線終】` | はさんだ部分に傍線 |
| `【赤字】` … `【字終】` | はさんだ部分を赤字に |
| `【穴】` … `【穴終】` | はさんだ部分を穴埋め枠に |
| `【枠】` `【左】` `【右】` `【上】` `【下】` … `【枠終】` 等 | 囲み罫・片側罫 |
| `【○テスト】` `【□テスト】` `【△テスト】` | 図形の中に文字 |
| `4/1` のような日付 | 日付マスとして表示 |

主なショートカットはアプリ内の **F1**（または `Ctrl + /`）で一覧表示できます。

## 🔐 セキュリティ設計（扱うデータ／扱わないデータ）

このツールは **サーバーを持ちません。** 配信元（GitHub Pages）は完成した HTML と JavaScript を
配るだけで、入力内容を受け取ることも記録することもありません。

### 扱わないデータ

- **児童の氏名・学籍番号・成績などの個人情報は一切扱いません。** 入力欄そのものがありません
- 利用者の行動ログ、アクセス解析、広告トラッカーの類は入れていません
- パスワードやトークンをアプリ側で保管することはありません

### 扱うデータと、その保存先

| データ | どこに保存されるか | 誰が見られるか |
|---|---|---|
| 編集中の設定（`notebookToolState_v3`） | 使っている端末のブラウザ内（localStorage） | その端末を使う人だけ |
| 保存したノート一覧（`notebookToolSavedNotes`） | 同上 | 同上 |
| 同期の ON/OFF 等の設定 | 同上 | 同上 |
| ノートのバックアップ（同期を使う場合のみ） | **ログインした先生ご本人の Google ドライブ** | そのアカウントの持ち主だけ |

### Google ドライブ同期について

- 使うかどうかは **任意** です。使わなくてもすべての機能が動きます
- 要求する権限は **`drive.file`（このアプリが作ったファイルだけ）** と、ログイン中のアカウントを
  画面に表示するための `openid` / `email` のみです。
  **先生の他のドライブのファイルには技術的にアクセスできません**
- 保存されるファイルは `notebook_sample_backup.json` の 1 つだけです
- 連携解除ボタンでアクセストークンを失効させ、端末側の接続情報も消去します
- 設定手順は [`docs/google-drive-sync.md`](docs/google-drive-sync.md) を参照してください

### 外部への通信先（これがすべてです）

| 宛先 | 用途 | いつ |
|---|---|---|
| `fonts.googleapis.com` / `fonts.gstatic.com` | 本文フォント（Zen Maru Gothic）の取得 | 初回表示時。以降はキャッシュ |
| `accounts.google.com` | Google ログイン画面 | 同期を使うときだけ |
| `www.googleapis.com` | ドライブへの読み書き | 同期を使うときだけ |

## ⚠️ 制限とクォータ

- **データは端末のブラウザに保存されます。** ブラウザの「閲覧履歴・サイトデータの削除」を実行すると
  保存したノートも消えます。大切なものは「データ管理」からエクスポートするか、
  Google ドライブ同期を有効にしてください
- **共用端末では注意してください。** 同じブラウザプロファイルを使う人は保存内容を見られます
- **削除は自動同期されません。** 取りこぼしを防ぐ統合方式のため、片方の端末で消しても、
  もう片方に残っていれば復活します。完全に消す場合は各端末で削除してください
- localStorage の容量上限は概ね 5MB 程度です。ノートを大量に保存すると保存に失敗することがあります
  （失敗しても既存データは壊れません）
- **印刷は A4 縦／横を前提**にしています。ブラウザの印刷設定で「背景のグラフィック」を
  有効にしてください（罫線や色が出ないときの原因はほぼこれです）
- PNG 書き出しは端末の性能に依存します。ページ数が多いと時間がかかります
- Google ドライブ API には利用者ごとの回数制限があります。通常の使い方で当たることはまず
  ありませんが、同期を短時間に繰り返すと一時的に失敗することがあります
- 教科書体（UD Digi Kyokasho）は **端末にインストールされている場合のみ**使われます。
  無い端末では代替フォントで表示されます

## 🛠 開発

```bash
npm ci          # 依存をインストール
npm run dev     # 開発サーバー（http://localhost:5173）
npm test        # テスト
npm run check   # 品質ゲート（必須ファイル・秘密情報・巨大ファイルの検査）
npm run quality # check と test をまとめて実行
npm run build   # 本番ビルド（dist/ に出力）
npm run preview # ビルド結果をローカルで確認
```

Google ドライブ同期をローカルで試す場合は、`.env.example` を `.env` にコピーして
`VITE_GOOGLE_CLIENT_ID` を設定してください（未設定でもビルドは通り、同期機能だけが
「初期設定が必要です」と表示されます）。

### 構成

| ファイル | 役割 |
|---|---|
| `src/App.jsx` | 画面の組み立て・用紙のレンダリング |
| `src/parseText.js` | 見本テキストの解析（文章 → マス目 → ページ）。React 非依存の純関数 |
| `src/googleDrive.js` | Google ドライブ連携（OAuth・読み書き・統合） |
| `src/useGoogleDriveSync.js` | 同期の状態管理フック |
| `vite.config.js` | ビルド設定・PWA マニフェスト |
| `tests/` | 中核ロジックのテスト（`node:test`。依存を増やさない方針） |
| `scripts/` | 品質ゲート。GIGA 共通の正本（SchoolPlan_Editor）と同一内容 |
| `quality.config.json` | 品質ゲートの設定（必須ファイル・除外ディレクトリ等） |

`main` ブランチへの push で GitHub Actions が
`npm audit` → `npm run check` → `npm test` → `npm run build` を実行し、
すべて通ったときだけ GitHub Pages へ公開します。
